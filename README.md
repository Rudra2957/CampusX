- Update for second PR

## Features
- **Dashboard:** Real-time weather, class schedule, attendance status, and campus events.
- - **Timetable:** Synchronized weekly class schedule tracking.
  - - **Attendance Tracker:** Dynamic calculations for maintaining the 75% attendance criteria.
    - - **Campus Navigation:** Facility directory and step-by-step walking routes.
      - - **Gemini AI Assistant:** AI assistant powered by Google Gemini.
        - - **Smart Canteen:** Pre-order food and track canteen orders.
          - - **Lost & Found:** Community board for recovered and missing items.
            - - **Emergency Contacts:** 24x7 security, medical, and helpline contacts.
